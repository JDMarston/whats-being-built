# Project Context

whatsthat.building is an early-stage app idea.

The basic idea:
People often walk or drive by a construction site and wonder what it is. This app answers that with a map.

Initial scope:
- St. Petersburg, FL
- construction projects
- developments
- notable buildings
- public links
- lightweight project info

Main constraint:
Spend as little money as possible. Use free tools first.

Potential future features:
- user submissions
- project status tracking
- permit/public record links
- neighborhood filters
- “near me” mode
- project timeline
- photos
