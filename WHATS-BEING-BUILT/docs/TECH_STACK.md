# Tech Stack

Current recommendation:
- React + Vite
- TypeScript
- MapLibre GL JS
- OpenStreetMap-compatible tiles
- Local GeoJSON/JSON data first
- Deploy later with Netlify or Vercel free tier

Avoid for now:
- paid map APIs
- backend database
- user accounts
- complex scraping
- paid domains
